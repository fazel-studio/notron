# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Debug store and related utilities for breakpoint management.
- Search and replace functionality in the editor.
- Initial project architecture with core UI components, terminal store, and Tauri backend integration.

## [0.1.0] - 2026

### Added

- Initial open-source release of Notron.
- File tree explorer with CRUD operations and real-time file watching.
- CodeMirror 6 editor engine with multi-tab and syntax highlighting.
- Command palette, symbol engine, and global search.
- Workspace restoration and theme support (Dark / Light / System).
- Markdown preview and image viewer.
- Integrated terminal and Git source control.
- Run & Debug support via DAP.
